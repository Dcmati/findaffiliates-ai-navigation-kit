# Contributing

Contributions are welcome if they improve public AI navigation, data extraction safety, or documentation clarity.

## Good contributions

• Clearer agent navigation instructions  
• Better examples for public URL discovery  
• Safer extraction schemas  
• Anti-hallucination rules  
• Responsible crawler guidance  
• Documentation fixes  

## Not accepted

• Private endpoints  
• Secret keys  
• Spam automation  
• Bypass instructions  
• Aggressive scraping code  
• Fake affiliate data  
• Claims not supported by public FindAffiliates pages  

## Style

Keep docs:

• Clear  
• Short  
• Source-based  
• Useful to agents and developers  
• Free of hype
