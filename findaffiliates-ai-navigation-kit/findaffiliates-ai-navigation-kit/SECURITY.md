# Security Policy

This repository is documentation-only.

It should not contain:

• API keys  
• Supabase credentials  
• Tally secrets  
• Make.com webhook URLs  
• Private crawler credentials  
• Internal admin routes  
• User data  
• Non-public program data  
• Browser automation that bypasses access controls  

## Reporting security issues

If you find a security issue related to FindAffiliates public documentation, contact the FindAffiliates owner through the website.

## Responsible automation

Agents and crawlers should only use public URLs and must respect `robots.txt`.
